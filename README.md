#To-Do List

Aplikasi to-do list sederhana yang dibuat dengan JavaScript. Ini proyek pertama saya untuk belajar JavaScript.

Demo: https://username.github.io/todo-list/

#Fitur
- Tambah tugas baru
- Centang tugas yang sudah selesai
- Hapus tugas (dengan konfirmasi)
- Filter: Semua / Aktif / Selesai
- Penghitung tugas yang belum selesai
- Data tersimpan di localStorage, jadi tidak hilang saat halaman di-refresh

#Teknologi
- HTML
- JavaScript (tanpa framework)
- Bootstrap 5

#Cara menjalankan
1. Unduh atau clone repo ini
2. Buka file `index.html` di browser

#Yang saya pelajari
- Manipulasi DOM dengan `createElement` dan `appendChild`
- Mengelola data dengan array of object
- Menyimpan data dengan localStorage dan JSON
- Pola data → simpan → render

#Rencana pengembangan
- Edit teks tugas
- Deadline untuk tiap tugas
- Mode gelap
